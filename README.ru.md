# BookMarkCore

Telegram-бот для сбора ссылок в один каталог. Готовая языковая модель предлагает категорию, а бот формирует HTML-карточку и публикует её через GitHub API.

[Код бота](main.py) · [Интерфейс каталога](index.html) · [English and setup](README.md)

## Пример

Отправляете боту ссылку на GitHub. Бот разбирает сообщение, предлагает категорию и проверяет, есть ли похожая запись в каталоге. При публикации ссылка появляется в соответствующем разделе HTML-страницы.

## Что есть в исходниках

- Асинхронные обработчики Telegram на aiogram.
- Разбор JSON-ответов модели и запасные варианты классификации.
- Проверка возможных дубликатов по нормализованной ссылке и названию.
- Публикация карточки в отдельный репозиторий через GitHub API.

Для запуска нужны собственные ключи и тестовый каталог с маркерами категорий. Инструкция есть в [README](README.md#setup-in-a-test-repository). Текст сообщения передаётся внешнему сервису моделей. Для демонстрации используйте общедоступные или искусственные примеры.
